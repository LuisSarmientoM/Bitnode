Especificación de Cache y Fallbacks para DIAN v2

Este documento define la capa de amortiguación con Redis Cluster para reducir la latencia de las respuestas emitidas por el portal de facturación de Alpina hacia los endpoints de validación previa de la DIAN.

NOTA TÉCNICA: La ventana de idempotencia exigida por la DIAN es de 120 segundos. Las solicitudes duplicadas dentro de este margen deben responderse directamente desde Redis usando el hash del payload canónico.

Requerimientos de invalidación y TTL

  • Documentos XML firmados: TTL persistente de 24 horas con clave prefijada factura:{nit}:{uuid}.
  • Validación de token OAuth2: Cache volátil de 50 minutos con renovación asíncrona mediante workers en background.
  • Catálogo de municipios y tarifas: Recarga semanal gatillada por evento Kafka en el tópico dian.catalogs.updated.
